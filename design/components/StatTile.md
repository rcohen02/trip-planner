# StatTile

A stat tile shows one number that matters: budget totals, weather, sunset.

- Label (caption or mono `label`), the value in `figure` (28px bold, tabular), one line of context in `ink-2`.
- Money and temperature show both units (see Writing). Example values here are illustrative.
- Use at most three or four in a row, only where the number is the point (Budget, Today's at-a-glance).
