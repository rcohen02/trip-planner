# StatusPill

A pill shows where a place is in the plan. Read-only; change status with the SegmentedControl or by dragging.

- Suggested: dashed outline, research found it and nobody has accepted it.
- Want: `want-bg` / `want-ink`. Planned: `planned-bg` / `planned-ink` (mint). Done: `done-bg` / `done-ink` (plum). Skipped: Want colors with a strike-through.
- Always show the word. Map status words to data values with the table in Writing.
