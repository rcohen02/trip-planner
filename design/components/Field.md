# Field

Text inputs and selects with the label above.

- Label in 12px `ink-3`, control `target` tall with a `control-border` border on `surface`.
- Errors set `aria-invalid="true"`: `crit` border, `crit-bg` fill, and a message under it that says how to fix it.
- Selects for cluster (West / Center / East), open day, status, day and slot. Search placeholders name what's searchable.
- Money inputs take local currency and show the USD conversion beside them ("auto at 1.16").
