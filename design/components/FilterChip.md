# FilterChip

Filter chips narrow a list by category. Toggle buttons with `aria-pressed`; one row that wraps.

- Each chip shows the category dot (`cat-*`), the name and the count.
- Selected: `accent` fill, `on-accent` text. "All" is selected by default and clears the others.
- Use chips for category only. Neighborhood cluster, open day and status are selects (see Field).
