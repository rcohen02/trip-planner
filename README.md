# T2T — Time 2 Travel

Private trip-planning dashboard. First trip: Lisbon, Oct 8–12, 2026; later trips can be anywhere.

- Plan and deploy steps: [`docs/TECHNICAL_APPROACH.md`](docs/TECHNICAL_APPROACH.md)
- Lisbon screens: [`docs/LISBON_SITEMAP.md`](docs/LISBON_SITEMAP.md)
- Trip content (imported into the site): `content/trips/`

Stack: Next.js · Prisma + Neon · Auth.js (Google) · Leaflet/OSM · Open-Meteo · Vercel (`*.vercel.app`) · GitHub Actions. Same patterns as `rcohen02/small-hall`.
